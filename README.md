# OS Portfolio 🚀

A modern, fast, and responsive **personal portfolio website** built to showcase projects, skills, and interests with a clean UI and smooth experience.

🔗 **Live Website:**  
👉 https://the-nitrozeus.github.io/os-portfolio/

---

## ✨ Features

- ⚡ Built with **Vite** for lightning-fast performance
- 🎨 Styled using **Tailwind CSS**
- 🧩 Written in **TypeScript** for type safety
- 📱 Fully **responsive** across devices
- 🧠 Clean and minimal UI focused on readability
- 🚀 Deployed using **GitHub Pages**

---

## 🛠️ Tech Stack

- **Frontend:** HTML, TypeScript
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Deployment:** GitHub Pages

---

## 📂 Project Structure

- **public/**
  - Static assets
- **src/**
  - Application source code
- **index.html**
  - Main HTML entry point
- **package.json**
  - Project dependencies
- **tailwind.config.js**
  - Tailwind CSS configuration
- **vite.config.ts**
  - Vite configuration
- **tsconfig.json**
  - TypeScript configuration
